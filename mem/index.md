# Project Memory

## Core
MyDropPocket põhimõte: kasutaja ei tee sama tegevust ega sisesta samu andmeid kaks korda. Üks tegevus käivitab kõik seotud automaatsed protsessid taustal (nt makse tasumine → märgi tasutuks + vähenda jääki + arvuta järgmine kuupäev + loo kulukanne automaatselt). AI ja automaatika vähendavad käsitsi tööd maksimaalselt.
Üks dokument = mitu funktsiooni: ostutšekk laaditakse üles ainult ÜKS kord. Kuludes ja Garantiides sama file_path — dokumenti ei dubleerita. AI pakub garantii-kandidaadid tšekilt (märgistatud 🤖), kasutaja kinnitab/muudab/lisab käsitsi. Salvestamisel luuakse expense + N warranties samast failist. Vastupidises suunas samamoodi. Kõik kirjed aktiivse profile_id alla.
